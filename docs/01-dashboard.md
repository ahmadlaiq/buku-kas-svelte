# 📊 Dashboard - Dokumentasi

## Deskripsi

Dashboard adalah halaman utama yang menampilkan ringkasan keuangan salon Anda secara real-time. Halaman ini memberikan gambaran cepat tentang kondisi keuangan salon dalam bulan berjalan.

## Fitur Utama

### 1. Statistik Keuangan

Dashboard menampilkan 5 metrik utama:

- **💰 Total Pendapatan**: Jumlah seluruh pendapatan bulan ini
- **💸 Total Pengeluaran**: Jumlah seluruh pengeluaran bulan ini
- **🏢 Beban Operasional**: Total biaya operasional bulan ini
- **📉 Beban Penyusutan**: Total penyusutan aset bulan ini
- **📈 Laba/Rugi Bersih**: Hasil akhir (pendapatan - semua biaya)

### 2. Indikator Visual

- Angka **hijau** menunjukkan keuntungan
- Angka **merah** menunjukkan kerugian atau pengeluaran
- Setiap kartu statistik memiliki animasi hover yang responsif

### 3. Transaksi Terbaru

Dashboard menampilkan:

- 5 pendapatan terakhir
- 5 pengeluaran terakhir
- Setiap transaksi menampilkan: tanggal, kategori, deskripsi, dan jumlah

### 4. Quick Actions

- Dari daftar transaksi, Anda bisa langsung klik "Lihat Semua" untuk melihat data lengkap

## Cara Menggunakan

### Membaca Dashboard

1. **Login** ke aplikasi terlebih dahulu
2. Setelah login, Anda otomatis diarahkan ke Dashboard
3. **Perhatikan angka Laba/Rugi Bersih** - ini adalah indikator utama kesehatan keuangan salon
4. **Review transaksi terbaru** untuk memastikan semua data tercatat

### Interpretasi Data

- **Laba Bersih Positif (Hijau)**: Salon Anda menguntungkan bulan ini ✅
- **Laba Bersih Negatif (Merah)**: Salon mengalami kerugian, perlu evaluasi biaya ⚠️

### Tips

- Cek dashboard setiap hari untuk monitoring real-time
- Bandingkan angka bulan ini dengan bulan sebelumnya
- Jika laba berkurang, evaluasi pengeluaran dan beban operasional
- Pastikan semua transaksi tercatat untuk data yang akurat

## Rumus Perhitungan

```
Laba Kotor = Total Pendapatan - Total Pengeluaran

Laba Bersih = Total Pendapatan - (Total Pengeluaran + Beban Operasional + Beban Penyusutan)
```

## Navigasi

- Klik menu **Pendapatan** untuk mencatat pemasukan
- Klik menu **Pengeluaran** untuk mencatat biaya
- Klik menu **Laporan** untuk melihat laporan lengkap

## Catatan Penting

⚠️ **Penting**: Dashboard hanya menampilkan data bulan berjalan. Untuk melihat data bulan lain, gunakan menu-menu individual atau halaman Laporan.

## Screenshot Elemen

- **Kartu Statistik**: Menampilkan angka besar dengan label di atas
- **Tabel Transaksi**: Format tabel dengan header warna pink gradien
- **Tombol Aksi**: Tombol "Lihat Semua" di bawah setiap tabel

## Troubleshooting

**Q: Mengapa angka di dashboard tidak berubah?**
A: Pastikan Anda sudah menambahkan transaksi di halaman yang sesuai (Pendapatan, Pengeluaran, dll)

**Q: Angka laba/rugi tidak sesuai?**
A: Periksa kembali semua transaksi di setiap menu, pastikan tidak ada yang terlewat atau salah input

**Q: Dashboard tidak muncul?**
A: Pastikan Anda sudah login. Jika belum, Anda akan diarahkan ke halaman login
